# CA - 3040 - SESSION - Block File Downloads On Unmanaged Devices

On a device that is not compliant: SharePoint, OneDrive and Exchange Online in the browser only, without downloads. For Exchange this only works with the OWA mailbox policy alongside it.

| | |
|---|---|
| Type | SESSION |
| State | disabled |
| Stage | 2 |
| Who | everyone |
| Excluded | `Excluded from Conditional Access`, `SG-U-CA-Exclude-Breakglass` |
| On | 2 apps: SharePoint Online (`00000003-0000-0ff1-ce00-000000000000`), Exchange Online (`00000002-0000-0ff1-ce00-000000000000`) |
| Conditions | Device filter: not on `device.isCompliant -eq True` |
| Requirement | app enforced restrictions |
| File | [`CA__3040__SESSION__Block_File_Downloads_On_Unmanaged_Devices.json`](CA__3040__SESSION__Block_File_Downloads_On_Unmanaged_Devices.json) |

Groups, named locations and authentication strengths in the table must exist in the tenant: see [`prerequisites/`](../prerequisites/README.en.md). An exclusion group that does not exist excludes nobody.

## Watch out

- For Exchange, per tenant: `Set-OwaMailboxPolicy -Identity OwaMailboxPolicy-Default -ConditionalAccessPolicy ReadOnly`. Without that step the policy is silent for Exchange.
