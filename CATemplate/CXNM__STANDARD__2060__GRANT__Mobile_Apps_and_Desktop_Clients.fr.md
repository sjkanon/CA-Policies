# CXNM - STANDARD - 2060 - GRANT - Mobile Apps and Desktop Clients

Exige un appareil conforme pour les applications mobiles et les clients de bureau. Microsoft Intune et Intune Enrollment sont exclus : sinon un appareil ne peut pas s'inscrire pour devenir conforme.

| | |
|---|---|
| Type | GRANT |
| State | disabled |
| Stage | 2 |
| Pour qui | tout le monde |
| Exclus | `Excluded from Conditional Access`, `SG-U-CA-Exclude-Breakglass`, `Conditional Access Service Accounts`, 1 rôles d'admin |
| Sur | toutes les apps, sauf Microsoft Intune (`0000000a-0000-0000-c000-000000000000`), Microsoft Intune Enrollment (`d4ebce55-015a-49b5-a083-c84d1797ae8c`) |
| Conditions | Clients: apps mobiles et clients de bureau |
| Exigence | appareil conforme |
| Fichier | [`CXNM__STANDARD__2060__GRANT__Mobile_Apps_and_Desktop_Clients.json`](CXNM__STANDARD__2060__GRANT__Mobile_Apps_and_Desktop_Clients.json) |

Les groupes, named locations et authentication strengths du tableau doivent exister dans le tenant : voir [`prerequisites/`](../prerequisites/README.fr.md). Un groupe d'exclusion qui n'existe pas n'exclut personne.

## Points d'attention

- Un PC ou téléphone personnel non inscrit dans Intune ne peut plus utiliser les apps Outlook, Teams ou OneDrive. À combiner avec `2070` pour les téléphones personnels.
