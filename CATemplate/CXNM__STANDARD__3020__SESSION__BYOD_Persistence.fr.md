# CXNM - STANDARD - 3020 - SESSION - BYOD Persistence

Sur un appareil non conforme : reconnexion toutes les 9 heures et pas de session de navigateur persistante. Report-only.

| | |
|---|---|
| Type | SESSION |
| State | report-only |
| Stage | 2 |
| Pour qui | tout le monde |
| Exclus | `Excluded from Conditional Access`, `SG-U-CA-Exclude-Breakglass` |
| Sur | toutes les apps |
| Conditions | Filtre d'appareil: pas sur `device.isCompliant -eq True` |
| Exigence | connexion toutes les 9 heures + pas de session de navigateur persistante |
| Fichier | [`CXNM__STANDARD__3020__SESSION__BYOD_Persistence.json`](CXNM__STANDARD__3020__SESSION__BYOD_Persistence.json) |

Les groupes, named locations et authentication strengths du tableau doivent exister dans le tenant : voir [`prerequisites/`](../prerequisites/README.fr.md). Un groupe d'exclusion qui n'existe pas n'exclut personne.
