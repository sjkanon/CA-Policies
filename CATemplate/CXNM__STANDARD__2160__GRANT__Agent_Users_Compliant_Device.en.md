# CXNM - STANDARD - 2160 - GRANT - Agent Users Compliant Device

Requires a compliant device for agent users that start a session from an endpoint. Report-only; requires Microsoft Entra Agent ID.

| | |
|---|---|
| Type | GRANT |
| State | report-only |
| Stage | 3* |
| Who | agent and workload identities |
| Excluded | — |
| On | all apps |
| Conditions | Agent context: `agentUserSessionsInitiatedFromEndpoints` |
| Requirement | compliant device |
| File | [`CXNM__STANDARD__2160__GRANT__Agent_Users_Compliant_Device.json`](CXNM__STANDARD__2160__GRANT__Agent_Users_Compliant_Device.json) |

Groups, named locations and authentication strengths in the table must exist in the tenant: see [`prerequisites/`](../prerequisites/README.en.md). An exclusion group that does not exist excludes nobody.

> **Optional** — vraagt Microsoft Entra Agent ID. Report-only: een agent-usersessie vanaf een endpoint dat (nog) niet compliant is valt hiermee stil, en welke endpoints agents gebruiken is in de meeste tenants nog niet in kaart.
